# Pameran Elemen HTML Lengkap - Media Pembelajaran HTML

Selamat datang di proyek Pameran Elemen HTML Lengkap! Proyek ini dirancang sebagai media pembelajaran yang praktis dan mudah diakses bagi siapa saja yang ingin memahami dasar-dasar HTML dalam satu halaman sehingga mempermudah proses pembelajaran dan menghemat waktu.

## Tujuan Proyek

Tujuan utama dari proyek ini adalah:

1.  **Mempermudah Pembelajaran HTML**: Menyajikan berbagai macam elemen HTML5 dalam satu halaman interaktif sehingga pengguna dapat melihat langsung contoh penggunaan dan struktur dasarnya.
2.  **Referensi Praktis**: Menjadi sumber referensi cepat bagi pengembang web, baik pemula maupun yang sudah berpengalaman, untuk mengingat kembali fungsi dan sintaks elemen-elemen HTML tertentu.
3.  **Demonstrasi Visual**: Memberikan gambaran visual tentang bagaimana elemen-elemen HTML dirender oleh browser, lengkap dengan sedikit sentuhan styling menggunakan Tailwind CSS agar lebih menarik dan mudah dibaca.
4.  **Pembelajaran Mandiri**: Mendukung proses belajar mandiri dengan menyediakan penjelasan singkat untuk setiap kategori elemen dan contoh kode yang jelas.

## Apa yang Akan Anda Temukan?

Dalam halaman ini, Anda akan menemukan demonstrasi dari berbagai kategori elemen HTML, termasuk:

* **Akar Pembagian (Sectioning Root)**: Struktur dasar dokumen HTML.
* **Pembagian Konten (Content Sectioning)**: Elemen-elemen seperti `<article>`, `<section>`, `<nav>`, dan `<aside>`.
* **Konten Teks (Text Content)**: Paragraf, heading, daftar, kutipan, dan lainnya.
* **Semantik Teks Inline (Inline Text Semantics)**: Penekanan teks, tautan, kode, dan format teks lainnya.
* **Gambar dan Multimedia (Image and Multimedia)**: Penyisipan gambar, audio, video, SVG, dan canvas.
* **Konten Tersemat (Embedded Content)**: Penggunaan `<iframe>`, `<embed>`, dan `<object>`.
* **Skrip (Scripting)**: Contoh penggunaan `<script>` dan `<noscript>`.
* **Menandai Perubahan (Demarcating Edits)**: Elemen `<ins>` dan `<del>`.
* **Konten Tabel (Table Content)**: Struktur tabel HTML yang lengkap.
* **Formulir (Forms)**: Berbagai jenis input, label, tombol, dan elemen formulir lainnya.
* **Elemen Interaktif (Interactive Elements)**: Penggunaan `<details>`, `<summary>`, dan `<dialog>`.

## Bagaimana Menggunakan Proyek Ini?

1.  **Unduh atau Clone**: Unduh file `index.html` dan file `index-id.html` (atau clone repositori jika tersedia).
2.  **Buka di Browser**: Buka file `index.html` atau file `index-id.html` di browser web modern pilihan Anda (misalnya Chrome, Firefox, Safari, Edge).
3.  **Eksplorasi**:
  * Gunakan **Daftar Isi** di bagian atas untuk melompat ke bagian elemen tertentu.
  * Perhatikan struktur HTML di dalam kode sumber (Anda bisa melihatnya dengan klik kanan pada halaman dan pilih "View Page Source" atau "Inspect Element").
  * Amati bagaimana setiap elemen ditampilkan di browser.
  * Baca deskripsi singkat yang menyertai setiap contoh elemen.
4.  **Modifikasi (Opsional)**: Jangan ragu untuk memodifikasi kode HTML dan CSS (Tailwind) untuk bereksperimen dan memperdalam pemahaman Anda.
