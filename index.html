1. Sectioning Root

The <body> element, which contains all the content of an HTML document, is the primary sectioning root. This entire page content is within the body.

2. Content Sectioning

<article> Element

This is an <article>. It represents a self-contained composition in a document, page, application, or site, which is intended to be independently distributable or reusable (e.g., in syndication). Examples include: a forum post, a magazine or newspaper article, or a blog entry.

<section> nested in article

This is a <section> within the article, used for grouping thematically related content.

<nav> Element

This <nav> block represents a section of a page whose purpose is to provide navigation links, either within the current document or to other documents. The table of contents above is another example.

  • Home (dummy)
  • About (dummy)

<aside> Element

This is an <aside>. It represents a portion of a document whose content is only indirectly related to the document's main content. Asides are frequently presented as sidebars or call-out boxes.

Heading Elements <h1> to <h6>

Heading 1 (<h1>) - Typically page title, used in header.

Heading 2 (<h2>) - Used for main section titles.

Heading 3 (<h3>) - Used for sub-section titles.

Heading 4 (<h4>) - Deeper level heading.

Heading 5 (<h5>) - Even deeper.
Heading 6 (<h6>) - The deepest heading level.
